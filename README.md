# অঙ্কিতা ঘোষ ও মলয় মাইতি — শুভ বিবাহ

A Bengali Bonedi Bari-inspired wedding invitation website for 25–26 January 2027.

## Included
- Bengali-language invitation with bride's name first
- Opening screen and animated sections
- Scratch-to-reveal date
- Countdown to 26 January 2027, 7:00 PM IST
- Four events only: আইবুড়োভাত, মেহেন্দি, গায়ে হলুদ, শুভ বিবাহ
- Family details and tap-to-call contact links
- Google Maps search link for Pingla Ghosh Cable Network
- Responsive layout for mobile and desktop

## Files
- `index.html` — page content
- `style.css` — design and responsive styling
- `script.js` — opening animation, music control, scratch reveal and countdown
- `assets/` — replace the sample SVG photo placeholders with your photographs

## Add wedding music
The player expects `assets/bengali-instrumental.mp3`. Add a royalty-free or properly licensed Bengali instrumental MP3 with that exact filename. Browsers require a user tap before audio can play; the opening button starts the music.

## Add photographs
Replace `assets/photo-1.svg`, `assets/photo-2.svg`, and `assets/photo-3.svg` with your own JPG/PNG photos. If using JPG, update the matching image filenames in `index.html`.

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `ankita-malay-wedding`.
2. Extract this ZIP and upload the contents of the `bengali-bonedi-wedding` folder (not the enclosing folder) to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then Save.
6. After deployment, GitHub will show your public website URL.
